# Assessoria Plugin QR Code Dinâmico

Código do plugin **QR Dinâmico • Placas & QR Codes Inteligentes** usado no painel da Kingdom Assessoria.

## Versão atual

**v1.2.8 — Tela cheia + experiência mobile**

Principais módulos:
- Dashboard
- QR Codes dinâmicos
- Clientes
- NFC / NTAG
- Vendas
- Analytics
- Usuários do painel
- Painel front-end via shortcode `[kingdom_painel]`

## Estrutura

- `plugin/` — código-fonte descompactado da versão atual.
- `releases/` — arquivo ZIP instalável no WordPress.
- `VERSION` — versão atualmente publicada neste diretório.

As próximas atualizações podem substituir o conteúdo de `plugin/` e adicionar uma nova versão em `releases/`.
